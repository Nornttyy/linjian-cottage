# 林间小筑

固定大地图、独立矿洞、采集、三层自由建造、种植、四类怪物和最多四人的共享世界。

公开网页：https://nornttyy.github.io/linjian-cottage/

GitHub Pages 托管游戏前端，Sites + D1 提供多人房间和持久存档。相同房间号可用于两个网页入口。

## 运行

需要 Node.js 22.13 以上版本。

```sh
npm install
npm run dev
```

本地世界保存在 `.local/worlds.sqlite`，线上使用 D1。浏览器保存房间连接凭证，以及各角色的快捷栏和背包排列；材料数量始终以服务器存档为准。

每个房间最多保留四个角色席位，离线后席位与角色进度仍保留；当前没有移除成员功能。

## GitHub Pages

```sh
npm run build:pages
npm run preview:pages
```

`main` 保存源码，`gh-pages` 只保存网页构建产物。在已登录 GitHub、源码已提交并推送后，运行 `npm run publish:pages` 更新网页分支。Pages 发布来源设为 `gh-pages` 分支根目录。

静态构建默认连接现有公开游戏后端。自建部署时，通过 `GAME_API_URL` 设置自己的接口地址、`PAGES_BASE_PATH` 设置仓库子路径，并把自己的 Pages 来源加入后端 CORS 允许列表。GitHub Pages 本身不运行数据库或游戏服务端。连接凭证保存在各网页来源自己的浏览器存储里。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 采集、攻击、放置 | 鼠标左键，可按住 |
| 切换九格快捷栏 | 1–9 / 鼠标滚轮 |
| 背包 | E；E / Esc 关闭 |
| 建造模式 | B |
| 拆除 | X，或建造时右键 |
| 闪避 | 空格 |
| 开关门、进出洞口、收获、上楼 | F；非建造模式也可右键点门 |
| 下楼 | Shift + F，或楼梯旁的下楼按钮 |
| 世界地图 | M |
| 使用精华恢复生命 | R |

背包有27格，支持拖放、点击交换和 Shift 快速移动。焦点停在物品格时，按1–9可交换到对应快捷栏；排列按房间和角色保存在当前浏览器。初始快捷栏放置常用工具；物品可自由移入、移出或交换，空格保持为空。新获得的材料进入背包；主界面快捷栏也可直接拖动交换。材料按种类累计，不做64个一组的拆分。

选择锤子或按 B 打开构件栏，显示对齐网格、目标格和锤子光标；楼梯显示2×2占地。材料清单直接列出所需与拥有数量，不足部分标色，楼梯费用随已有上层落脚地板变化。清理陆地后铺地板，墙、门窗、屋顶及家具需要地板。横竖墙和转角共用连续轮廓，墙厚6逻辑像素，碰撞也按实际墙体计算。门可以反复开关，关门时只检查门扇占用范围。

楼梯需要2×2地板，放置后自动补齐上一层2×2落脚地板；两层的出入口均预留，墙、门窗和家具不能盖住洞口。可在同坐标继续搭上一段楼梯，但不能错位重叠。按 F 上楼，在上层继续铺地板、建墙和楼梯，最多三层。上层地板必须有下层地板支撑，下方不能已有屋顶。拆除时保留楼上支撑和回到地面的通路，楼上有玩家时不能拆楼梯；拆除按屋顶、家具、墙、地板顺序返还材料。屋顶与上层遮挡在300ms内渐隐或恢复，中途反向保持连续。

使用锄头开垦草地或林地，选种子播种，再用水壶浇水。胡萝卜、番茄、小麦都有四阶段生成素材，分别累计浇水生长90、120、150秒；一次浇水维持100秒，干燥时暂停生长。成熟后点击作物或靠近按 F 收获，得到作物和两粒同种种子。非建造模式下空手或拿任意物品都能点击成熟作物收获。收获后耕地立即变干；空干耕地在60秒内逐渐恢复原来的草地，已有作物的干地仍保留。胡萝卜和番茄可放到快捷栏食用。农田、种子和生长进度由房间共享并持久保存。

地面的栅栏、花盆、提灯和告示牌可以直接放在陆地上，上层仍需要地板。告示牌可点击或靠近按 F 查看、编辑和保存，最多240字，房间中的玩家共享内容。

把鱼竿放到快捷栏，在岸边点击水面钓鱼。营火旁按 F 或点击营火烹饪，按顺序使用1条鱼、2根胡萝卜、2个番茄或3份小麦，制作1份熟食；熟食放到快捷栏点击食用。床由建造锤放置在地板上，靠近按 F 或点击床休息，移动会起床。收获、采摘浆果、吃东西、翻滚、钓鱼、烹饪和睡觉各使用独立的方向动作图集。

斧、镐、剑和农具动作期间锁定移动与朝向，动作结束即可继续走；下一次动作等待本次确认，不积压连续攻击。斧和镐挥动360ms，剑280ms。采集和战斗在本地接触帧立即表现命中，材料和伤害仍由服务端核验；确认不会再次播放命中表现。迟到请求保留移动历史，减少出手或翻滚后拉回。

网络使用固定发送节拍、增量快照与各自独立完成的请求，保留重试去重、碰撞和身份校验。四人状态下跨节点数据库竞争与实际网络往返仍会影响新动作确认；并非实时套接字服务器，不能保证所有网络环境低延迟。

野外有史莱姆、蓄力冲刺的野猪，矿洞有蝙蝠和蘑菇怪。蘑菇怪会标记范围后释放孢子；不同怪物有各自的待机、移动、攻击、受击与死亡帧。营火附近恢复生命。

铜石矿洞位于地表地图东北矿区，地图上的洞口图标可标记方向与距离，沿路有路牌。走进洞口，或靠近洞口按 F，进入固定的 96 × 96 洞内地图；从洞内南侧出口返回地表。洞内进度与同一房间共享，保留背包和地表建造进度。

## 验证

```sh
npm test
npm run build
```

`npm test` 在内存数据库中执行全部规则、动作、联机与存档回归检查，不访问真实房间。 `node scripts/check-workers-lifecycle.mjs` 在本机启动 workerd 和独立 D1，检查冷启动、四人并发、首请求提前结束与取消后的请求独立性；需要允许本地端口监听。设置 `GAME_API_URL` 后单独运行 `node scripts/test-room.mjs` 可创建独立测试世界验证指定后端。

回归测试覆盖短按移动、转向顺序、延迟确认、请求重试、连续采集、右键拆除、怪物出生点和屋顶预览坐标。此类检查不代替浏览器中的完整实机操作检查。

动作测试覆盖延迟确认不倒退、不抹除或重播出招，出招朝向和工具锁定，以及动作接触帧与服务端伤害时机的一致性。

移动锁和输入延迟测试覆盖三种工具的完整挥动、持续方向键恢复、即时请求、重连、重复输入、联机确认、翻滚历史速度回放，以及史莱姆真实移动状态。连续采集检查已接受的动作只执行一次，松开后没有后续动作积压。

延迟移动测试覆盖300–1800ms往返延迟及波动、走出门口后立即关门、墙边碰撞和翻滚恢复。服务端按真实经过的时间接收最多8秒移动历史，保留速度、碰撞和重复输入校验，避免延迟包被截断后将角色拉回。背包测试执行真实组件事件和客户端操作；屋顶、窄墙测试覆盖过渡反向、画布隔离和各方向连接。

## 素材

所有正式角色、怪物、树木、矿石、地形、建筑、洞口和工具图标均通过内置图片生成工具生成。最终素材、图集布局及对应提示词见 `public/art/ASSETS.md`。游戏视图没有 emoji、任务说明卡或大段引导。

角色保留原先完整的待机人物，只作轻微呼吸和间歇眨眼。行走、砍树、挖矿、挥剑重新生成，每种动作有下、上、右各8帧，左向镜像；以原人物的长袖和身体宽度统一动作外观，各方向固定比例与脚底锚点。受击、闪避仍使用原始完整动作帧。攻击判定安排在接触帧，斧、镐和剑配有各自8帧的生成光轨；刀光随固定出手方向播放，在接触时最亮，收招结束即消失。命中产生短暂木屑、石屑或火花。场景采用柔和暖日光、轻树影、温暖火光、水面微光和缓慢浮尘。

史莱姆进入行走时从首帧起步，受击和攻击收势期间停住；延迟快照中的攻击也会正常结束。显示位置按快照间隔通过90–950ms过渡衔接，身体、阴影和血条一起移动，服务端碰撞及伤害坐标保持不变。

地形边界和材质预先合成缓存，资源通过空间索引查询；地块缓存最多2048格，约4.5MiB原始像素。缓存不包含建筑、资源剩余状态或动态水面，因此采集与建造仍能即时更新。

新增19种原创程序生成音效及环境声，首次按键或点击后启用；右上角可关闭。暖日光、柔和色调、树影、火光与浮尘共同营造明亮温暖的氛围。

尚未实现烹饪、钓鱼和多层矿洞。

固定地图新增弯曲小径、林间草甸、不同树种及古木林心、霜石垒、日光石环、萤草甸四处自然地标。河水以连续波纹流动，河岸与桥梁位置不变。原有4597处资源、矿洞通道和存档建筑均保留。世界地图显示地标和已建房屋。

人物、怪物、作物、篝火及材质从原生成图片直接以两倍像素密度采样；角色大小、视野、脚点和碰撞坐标不变，背包图标同步提升绘制密度。

打开游戏先进入主菜单，可继续、新建或输入房间号加入。新手引导依据实际移动、获得木材、铺地板、建墙和命中怪物推进；支持跳过，在游戏菜单中重看。引导进度按房间与角色保存在当前设备，退出菜单不清除世界和快捷栏。
