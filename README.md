# 林间小筑

第一版实现固定大地图、独立矿洞、采集、单层模块化建造、史莱姆战斗和最多四人的共享世界。

公开网页：https://nornttyy.github.io/linjian-cottage/

GitHub Pages 托管游戏前端，Sites + D1 提供多人房间和持久存档。相同房间号可用于两个网页入口。

## 运行

需要 Node.js 22.13 以上版本。

```sh
npm install
npm run dev
```

本地世界保存在 `.local/worlds.sqlite`，线上使用 D1。浏览器只保存房间连接凭证。

每个房间最多保留四个角色席位，离线后席位与角色进度仍保留；当前没有移除成员功能。

## GitHub Pages

```sh
npm run build:pages
npm run preview:pages
```

`main` 保存源码，`gh-pages` 只保存网页构建产物。在已登录 GitHub、源码已提交并推送后，运行 `npm run publish:pages` 更新网页分支。Pages 发布来源设为 `gh-pages` 分支根目录。

静态构建默认连接现有公开游戏后端。自建部署时，通过 `GAME_API_URL` 设置自己的接口地址、`PAGES_BASE_PATH` 设置仓库子路径，并把自己的 Pages 来源加入后端 CORS 允许列表。GitHub Pages 本身不运行数据库或游戏服务端。连接凭证保存在各网页来源自己的浏览器存储里。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 采集、攻击、放置 | 鼠标左键，可按住 |
| 斧、镐、剑、建造 | 1 / 2 / 3 / 4 |
| 建造模式 | B |
| 拆除 | X，或建造时右键 |
| 闪避 | 空格 |
| 开关门 | E |
| 世界地图 | M |
| 使用精华恢复生命 | R |

斧、镐和剑在挥动期间锁定移动与朝向，结束后恢复；仍按住方向键即可继续行走。斧和镐挥动360ms，剑280ms。动作立即发送，连续按住只在当前动作结束后发起下一次，松开后不会积压补放。挥动与闪避互斥；联机确认期间仍保留移动锁，较高延迟会影响恢复时间。

地板可以铺在清理后的陆地上；墙、门窗和屋顶需要地板。拆除按屋顶、墙、地板顺序返还材料。进入相连的地板区域后，对应屋顶淡出。营火附近恢复生命。

铜石矿洞位于地表地图东北矿区。走进洞口，或靠近洞口按 E，进入固定的 96 × 96 洞内地图；从洞内南侧出口返回地表。洞内进度与同一房间共享，保留背包和地表建造进度。

## 验证

```sh
npm test
node scripts/test-regression.mjs
node scripts/test-animation.mjs
node scripts/test-movement.mjs
node scripts/test-input-latency.mjs
node scripts/test-room.mjs
npm run build
```

房间接口测试需要本地预览运行。接口测试创建独立的测试世界。

回归测试覆盖短按移动、转向顺序、延迟确认、请求重试、连续采集、右键拆除、怪物出生点和屋顶预览坐标。此类检查不代替浏览器中的完整实机操作检查。

动作测试覆盖延迟确认不倒退、不抹除或重播出招，出招朝向和工具锁定，以及动作接触帧与服务端伤害时机的一致性。

移动锁和输入延迟测试覆盖三种工具的完整挥动、持续方向键恢复、即时请求、重连、重复输入、联机确认、翻滚历史速度回放，以及史莱姆真实移动状态。连续采集检查已接受的动作只执行一次，松开后没有后续动作积压。

## 素材

所有正式角色、怪物、树木、矿石、地形、建筑、洞口和工具图标均通过内置图片生成工具生成。最终素材、图集布局及对应提示词见 `public/art/ASSETS.md`。游戏视图没有 emoji、任务说明卡或大段引导。

角色恢复原先完整的像素人物图集与身体比例，行走、砍树、挖矿、挥剑、受击、闪避各使用8张原始动作帧。待机沿用原人物完整中性帧，仅轻微呼吸和间歇眨眼；攻击判定安排在接触帧。场景采用柔和暖日光、轻树影、温暖火光、水面微光和缓慢浮尘。

地形边界和材质预先合成缓存，资源通过空间索引查询；地块缓存最多2048格，约4.5MiB原始像素。缓存不包含建筑、资源剩余状态或动态水面，因此采集与建造仍能即时更新。

第一版没有种田、烹饪、钓鱼、二层建筑或多层矿洞；这些属于后续内容。
