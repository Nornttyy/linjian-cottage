# 林间小筑

第一版实现固定大地图、独立矿洞、采集、单层模块化建造、史莱姆战斗和最多四人的共享世界。

公开网页：https://nornttyy.github.io/linjian-cottage/

GitHub Pages 托管游戏前端，Sites + D1 提供多人房间和持久存档。相同房间号可用于两个网页入口。

## 运行

需要 Node.js 22.13 以上版本。

```sh
npm install
npm run dev
```

本地世界保存在 `.local/worlds.sqlite`，线上使用 D1。浏览器保存房间连接凭证，以及各角色的快捷栏和背包排列；材料数量始终以服务器存档为准。

每个房间最多保留四个角色席位，离线后席位与角色进度仍保留；当前没有移除成员功能。

## GitHub Pages

```sh
npm run build:pages
npm run preview:pages
```

`main` 保存源码，`gh-pages` 只保存网页构建产物。在已登录 GitHub、源码已提交并推送后，运行 `npm run publish:pages` 更新网页分支。Pages 发布来源设为 `gh-pages` 分支根目录。

静态构建默认连接现有公开游戏后端。自建部署时，通过 `GAME_API_URL` 设置自己的接口地址、`PAGES_BASE_PATH` 设置仓库子路径，并把自己的 Pages 来源加入后端 CORS 允许列表。GitHub Pages 本身不运行数据库或游戏服务端。连接凭证保存在各网页来源自己的浏览器存储里。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 采集、攻击、放置 | 鼠标左键，可按住 |
| 切换九格快捷栏 | 1–9 / 鼠标滚轮 |
| 背包 | E；E / Esc 关闭 |
| 建造模式 | B |
| 拆除 | X，或建造时右键 |
| 闪避 | 空格 |
| 开关门、进入洞口 | F；非建造模式也可右键点门 |
| 世界地图 | M |
| 使用精华恢复生命 | R |

背包有27格，支持拖放、点击交换和 Shift 快速移动。焦点停在物品格时，按1–9可交换到对应快捷栏；排列按房间和角色保存在当前浏览器。工具、建造图纸和材料共用格子；标记“建”的图纸放置时消耗材料。材料按种类累计，不做64个一组的拆分。

斧、镐和剑在挥动期间锁定移动与朝向，结束后恢复；仍按住方向键即可继续行走。斧和镐挥动360ms，剑280ms。动作立即发送，连续按住只在当前动作结束后发起下一次，松开后不会积压补放。挥动与闪避互斥；联机确认期间仍保留移动锁，较高延迟会影响恢复时间。

地板可以铺在清理后的陆地上；墙、门窗和屋顶需要地板。拆除按屋顶、墙、地板顺序返还材料。墙体按相邻门窗和墙自动衔接，竖墙显示为8像素宽，建造和碰撞仍使用24像素格子。进入或离开相连的地板区域时，屋顶在300ms内渐隐或恢复；中途反向也保持连续。营火附近恢复生命。

铜石矿洞位于地表地图东北矿区。走进洞口，或靠近洞口按 F，进入固定的 96 × 96 洞内地图；从洞内南侧出口返回地表。洞内进度与同一房间共享，保留背包和地表建造进度。

## 验证

```sh
npm test
node scripts/test-regression.mjs
node scripts/test-animation.mjs
node scripts/test-movement.mjs
node scripts/test-input-latency.mjs
node scripts/test-door-latency.mjs
node scripts/test-inventory.mjs
node scripts/test-roof-visibility.mjs
node scripts/test-connected-walls.mjs
node scripts/test-slime.mjs
node scripts/test-tool-effects.mjs
node scripts/test-room.mjs
npm run build
```

房间接口测试需要本地预览运行。接口测试创建独立的测试世界。

回归测试覆盖短按移动、转向顺序、延迟确认、请求重试、连续采集、右键拆除、怪物出生点和屋顶预览坐标。此类检查不代替浏览器中的完整实机操作检查。

动作测试覆盖延迟确认不倒退、不抹除或重播出招，出招朝向和工具锁定，以及动作接触帧与服务端伤害时机的一致性。

移动锁和输入延迟测试覆盖三种工具的完整挥动、持续方向键恢复、即时请求、重连、重复输入、联机确认、翻滚历史速度回放，以及史莱姆真实移动状态。连续采集检查已接受的动作只执行一次，松开后没有后续动作积压。

延迟移动测试覆盖300–1800ms往返延迟及波动、走出门口后立即关门、墙边碰撞和翻滚恢复。服务端按真实经过的时间接收最多8秒移动历史，保留速度、碰撞和重复输入校验，避免延迟包被截断后将角色拉回。背包测试执行真实组件事件和客户端操作；屋顶、窄墙测试覆盖过渡反向、画布隔离和各方向连接。

## 素材

所有正式角色、怪物、树木、矿石、地形、建筑、洞口和工具图标均通过内置图片生成工具生成。最终素材、图集布局及对应提示词见 `public/art/ASSETS.md`。游戏视图没有 emoji、任务说明卡或大段引导。

角色保留原先完整的待机人物，只作轻微呼吸和间歇眨眼。行走、砍树、挖矿、挥剑重新生成，每种动作有下、上、右各8帧，左向镜像；以原人物的长袖和身体宽度统一动作外观，各方向固定比例与脚底锚点。受击、闪避仍使用原始完整动作帧。攻击判定安排在接触帧，斧、镐和剑配有各自8帧的生成光轨；刀光随固定出手方向播放，在接触时最亮，收招结束即消失。命中产生短暂木屑、石屑或火花。场景采用柔和暖日光、轻树影、温暖火光、水面微光和缓慢浮尘。

史莱姆进入行走时从首帧起步，受击和攻击收势期间停住；延迟快照中的攻击也会正常结束。显示位置通过80–120ms过渡衔接，身体、阴影和血条一起移动，服务端碰撞及伤害坐标保持不变。

地形边界和材质预先合成缓存，资源通过空间索引查询；地块缓存最多2048格，约4.5MiB原始像素。缓存不包含建筑、资源剩余状态或动态水面，因此采集与建造仍能即时更新。

第一版没有种田、烹饪、钓鱼、二层建筑或多层矿洞；这些属于后续内容。
