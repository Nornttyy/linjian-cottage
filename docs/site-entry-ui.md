# 网站入口与林间手帐界面（2026-09-15）

网页打开后立即显示松林绿底色、像素提灯、林间来信标题与等待状态。启动壳直接写入 GitHub Pages 的 HTML 和多人站点的服务器页面，在游戏脚本下载之前可见；脚本加载较慢时出现重新加载按钮。两端共用 `lib/site-entry-shell.ts`。

`SiteEntry` 预热现有素材加载器和菜单背景，显示真实的已加载素材数量；素材齐全后仍等待图集处理与背景准备完成，再淡出进入菜单。浏览器缓存提前完成或失败的背景图片也会被检查。加载失败可重试，也可先去主菜单；后台已完成的素材会被角色预览和游戏复用，不会预先创建世界、连接房间或修改存档。

主菜单采用森林来信样式，有编号的操作、简短用途说明、继续旅程提示与独立的新手引导入口。角色选择采用旅人名册样式，仍在点新世界或继续游戏之后出现，并保留添加角色、命名与换装。进入世界的加载页、背包、房间窗口、烹饪界面和工具栏统一使用松林绿、羊皮纸色、蜂蜜金和方形边框。

保留现有背景插画、角色和场景像素素材、日夜亮度及玩法。适配窄屏、矮屏、触屏安全区域、键盘焦点和减少动态效果的系统偏好；未额外加载网络字体。
