# 角色动作与调色修复

针对连续播放才出现的错位、漏色和串色，沿用现有男女角色及正式服装素材。

- 挥镐落下时，镐刃不再参与裤子识别；两条裤腿分别覆盖，腰部定位使用两腿之间的位置，避免因遮挡左右跳动。
- 脸部以完整肤色区域识别，不再误选头发上的小块高光；翻滚、睡眠时补齐分离的袖口和头发。
- 翻滚时单独识别抬起的靴子及与手掌相接的靴沿；裤子完全遮住的帧使用审阅过的身体锚点。
- 肤色、头发、眼睛、鞋袜和装饰的像素归属互不重叠，避免腰带色染到靴子、肤色改变鞋子。
- 男角色背向翻滚的头部被身体遮挡帧，保留正确的身体轴向并隐藏被挡住的头饰，避免把靴子识别成头。
- 挥斧、挥镐、挥剑、锤击、耕作与收获的 288 个动作使用逐帧工具/收获物遮罩，避免金属被当成裤子、木柄被当成头发、木锤与靴子被当成肤色；眼睛颜色也遵守同一边界。
- 裤腿上的青色高光根据所属衣片归入裤子，不再跟随上衣颜色。
- 48 个钓鱼动作记录了原素材中的竿尖与握持位置。鱼竿从头发识别中分离，换色及穿戴不会改变鱼竿或带偏头饰。
- 移除抛竿素材中多余的静态鱼线；实际鱼线从当前动作的竿尖连接到浮漂，并对应角色身体与左右镜像。
- 旋转后的新服装、头饰图层使用清晰的像素透明边界，保留原角色素材的透明度。

`scripts/fixtures/hero-dye-actions.json` 保存原正式图集的 347 个无损运行时帧，用于直接验证脸、工具、裤腿、靴子、腰部定位和钓鱼动作，避免仅用几何色块测试。`scripts/test-appearance.mjs` 包含对应回归检查。

发布前另用实际素材加载器与画布渲染器遍历 960 个角色动作、6 套外装/泳装组合，核对工具遮挡、脸部颜色、非空图像和画布边界，并检查连续动作预览。上线状态以远端资源校验结果为准。

## 上一版身体轮廓与动作漂移复查（泳装拼接方案已替换）

- 女角色钓鱼、做饭图集仍有逐格水平漂移。新增 `hero-registration.ts` 记录 48 帧脚底修正，完成染色和穿戴后整体平移，保持头脸、身体和工具的相对位置及原始比例。鱼线起点同步修正并支持左右镜像。
- 泳装不再沿每条衣物扫描线削边，避免裤缝、屈膝、举手时产生透明缺口。躯干根据头部与胯部距离压缩，弯腿仍使用原动作轮廓；站立动作的脚部使用现有正式泳装图集中的裸足，按原脚底定位。
- 裸露皮肤统一采用各自原站姿脸部的肤色基准，保留自由调色，消除逐帧取样造成的偏黄、偏粉和忽明忽暗。脸、眼睛、头发、发绳、手部和工具保持各自图层归属。补全女角色蹲下锤击时的右靴边界。
- 未重新生成或替换原角色脸部、头发和场景素材。本轮复用已生成的正式泳装素材，修正组合及定位代码。

`scripts/test-hero-shape.mjs` 使用 234 个真实动作与泳装素材缓冲区验证脚底稳定、完整像素平移、鱼线镜像、头脸保护、举手时身体连续性及发绳颜色。自动检查不等同于对每个动作美术效果的主观确认。

现行外装与泳装的完整动作实现及验证范围见 [完整服装动作图集](full-body-outfits.md)。`test-hero-shape.mjs` 目前保留原角色脚底定位、整体平移及钓线镜像检查；已删除被完整动作替代的泳装拼接检查。
