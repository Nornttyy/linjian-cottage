# 角色、厨房与营地更新

- 主菜单点击“新世界”“继续游戏”等入口后，再选择角色；选择完成才创建或连接世界。首次打开会把原来的继续游戏存档保留为“旅人”。每位角色独立保存上次进入的世界，背包和食谱仍随该世界保存。
- 烹饪允许自由组合 1～5 份食材。做法和主要食材决定料理，其他配料及用量改变每份成品的生命、体力恢复值。只放调味料或缺少适合该做法的主食材时不能开做。
- 未做出的搭配不预告菜名和恢复值。成功完成后自动清空食材槽，并记录实际配料、产量和效果；取消或失败时保留选择。同一道料理可以发现多个搭配。成品按制作顺序食用，背包说明显示下一份的实际效果。旧存档的料理保留原来的效果。
- 钓鱼小游戏持续使用持竿姿势，成功结束后只收竿一次；受伤或移动打断时不重播收竿。
- 夜晚使用明显的冷色暗光，无灯处更暗，移除跟随角色的光源，只有固定提灯、篝火和洞穴火把照亮周围，清晨与黄昏平滑过渡。
- 窗户与木墙共用墙面和顶面木材，只叠加窗框和玻璃；木墙和窗户图标直接显示对应建筑外观。
- 树木倒下后的木桩可以再用斧头清除，额外获得 1～3 个木头。木桩清除状态随世界保存，不能重复领取。
- 建造锤新增“篝火”，消耗 8 木头、4 石头。新篝火会照明，同楼层靠近时可按 F 或点击打开厨房。烹饪完成前移走篝火会取消制作。
