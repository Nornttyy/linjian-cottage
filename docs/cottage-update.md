# 角色、厨房与营地更新

- 主菜单点击“选择角色”可创建、改名和切换旅人。首次打开会把原来的继续游戏存档保留为“旅人”。每位角色独立保存上次进入的世界，背包和食谱仍随该世界保存。
- 烹饪允许自由组合 1～5 份食材。做法和主要食材决定料理，其他配料及用量改变每份成品的生命、体力恢复值。只放调味料或缺少适合该做法的主食材时不能开做。
- 未做出的搭配不预告菜名和恢复值。成功完成后记录实际配料、产量和效果；同一道料理可以发现多个搭配。成品按制作顺序食用，背包说明显示下一份的实际效果。旧存档的料理保留原来的效果。
- 钓鱼小游戏持续使用持竿姿势，成功结束后只收竿一次；受伤或移动打断时不重播收竿。
- 夜晚使用明显的冷色暗光，角色附近保留能见度，提灯和篝火照亮周围，清晨与黄昏平滑过渡。
- 树木倒下后的木桩可以再用斧头清除，额外获得 1～3 个木头。木桩清除状态随世界保存，不能重复领取。
- 建造锤新增“篝火”，消耗 8 木头、4 石头。新篝火会照明，同楼层靠近时可按 F 或点击打开厨房。烹饪完成前移走篝火会取消制作。

2026-09-14 验证：771 项自动化检查、TypeScript、ESLint、GitHub Pages 构建和服务端构建通过。当前多人端点仍只返回旧网络协议能力，未提供这次功能的部署接口；新增玩法在“本机世界”使用。服务端代码已同步准备，新版客户端会检查服务器能力，避免把旧房间当成新版。
