# 女角色、换装与料理实验（2026-09-14）

角色选择仍在点击新世界、继续游戏、本机世界或加入之后出现。新增完整成年女角色，独立的身形、较丰满的胸部轮廓、眼睛、肤色与发型；原男角色素材保持原样。上衣、裤子各有九种颜色，角色资料、继续游戏和多人同步均保存外观。

女角色正式素材为 `public/art/female-*-v1.png`，对应生成提示词为同名 `.prompt.txt`。内置图片工具生成了17套完整动作图集，共408个原始姿势；运行时包含眨眼时序，共480帧。动作注册与加载清单分别见 `lib/female-art-layout.ts`、`lib/art.ts`、`lib/asset-loading.ts`。全部为真正带透明通道的PNG。按用户授权，生成图中的误画棋盘格或色键背景由 `scripts/export-transparent-atlas.mjs` 去除；图案未用代码重画。挖矿和浇水最后采用内置工具生成的纯色背景中间稿，再导出透明素材。

新料理图集 `public/art/food-odd-v1.png` 与提示词文件包含怪味糊糊、焦木脆片、石头焗饭、铜锅焦团、星露布丁、奇光饭团、种籽薄饼、海陆大杂烩、剩菜乱炖。原30种料理及16种新增食材素材保留，目前共55个新增食物图标。

烹饪仍为1～5份材料，成功做出后记录具体做法，不预先公开全部食谱。同一道正常料理允许合理替换与配料变化，不同配方保留各自恢复效果。种子、木石铜、精华和剩菜也可尝试入锅；食材与做法不合适时产出低恢复或零恢复的奇葩料理。五类较合理的特殊料理可通过不同搭配改变效果。食材在结算时立刻消耗并清空选择；剩菜消耗原料理批次，防止恢复效果错位。旧存档已做出的料理保留原有恢复效果。

服务器新增 `cookingVersion:3`，沿用 `networkVersion:2`、`activityVersion:2`、`cottageVersion:2`。客户端检查服务能力后才发送对应操作，避免旧服务错误结算新料理。
