# 林间旅程、换装与角色表现

延续现有世界、角色、钓鱼、自由烹饪和存档，不重做游戏。

## 本轮内容

- 精简入口与菜单文字，保留真实加载进度、失败重试和选择角色流程。
- 21 项可收起的新手旅程：实际搭建能进出的 3×3 小屋、种菜、做饭、准备补给、下矿、战斗、回家点灯与休息；按角色和世界保存进度，不要求寻找服装。
- 可选主线「重亮林间驿站」：留饭、认识古木与矿洞、修复路灯。接取、追踪、停止追踪独立于普通游玩。多人共享修好的固定路灯。
- 18 类独立像素粒子，分别绘制木屑、矿屑、水花、孢子、热气等。伤害与资源效果跟随真实目标，预测反馈不会重复生成。
- 死亡倒地动画与界面；保留背包、装扮，完成倒地过程后可主动回营地，重连保留死亡状态。
- 4 种头饰、4 种外装、2 套泳装；探索、收获、钓鱼解锁，服务器验证所有权与加成。
- 普通外装和泳装都使用完整身体动作图，衣物直接随本体动作。男款为贴身短袖泳衣与泳裤，女款为比基尼。泳装需先探索并钓获一定次数，穿上后可游泳。
- 身体 7 个调色区：头发、肤色、眼睛、上衣、下装、鞋袜、身体装饰；穿戴对应装扮后另有外装主色、外装花纹、头饰主色。各区均支持任意六位十六进制颜色。
- 修正蓝色袖子阴影被误当成裤子、浅色高光和深色接缝漏色、头发高光、手部肤色、女性眼睛及发绳染色；浇水壶单独保护，外装染色与身体颜色独立。
